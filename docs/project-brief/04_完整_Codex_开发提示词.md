# 给 Codex 的完整开发提示词（请完整执行）

你是资深全栈工程师与图像处理工程师。请在当前工作区直接创建、实现、测试并完善 AI 素材工厂 MVP，不要只给建议或伪代码。先阅读同目录的 PRD、架构、开发计划和 API 说明。

## 业务目标
制作简体中文轻量 Web 应用，供 1–4 名内部员工使用，每周处理几十张授权卡通人物拼图。员工批量选择图片，点击“一键提取无水印人物”，自动执行水印区域定位/修复、卡通人物实例分割、透明 PNG 导出。不租 GPU、不维护 GPU 服务器，图片和结果尽量留在用户本地。

## 技术核验先行
1. 阅读官方文档：https://api-docs.deepseek.com/zh-cn/
2. 默认可编辑模型 ID 设为用户提供的 `deepseekv4.1flash1017`，但必须提醒用户核实是否为 API 接受的精确 ID，不要擅自改写。
3. 确认 API 是否支持视觉输入、图片传输格式、输出结构、是否能输出/编辑图片。
4. 不得把多模态理解能力等同于图像修复或像素级实例分割。
5. 无法访问官方文档时，不要猜 endpoint 或请求格式；先实现 provider interface、配置页和 mock 测试，并标记待用户提供真实请求样例。

## 技术要求
- React + TypeScript + Vite。
- 桌面浏览器优先，简体中文。
- CPU 密集操作尽量使用 Web Worker。
- 定义 DeepSeekProvider、WatermarkRepairProvider、CharacterSegmentationProvider 三个接口。
- 业务代码通过 adapter 调模型，避免绑定单一供应商。
- 原图读取、预览、导出尽量在浏览器端完成。
- API Key 设置页输入、掩码显示；不能硬编码进源码、Git 或日志。README 必须说明纯前端直连不能真正隐藏 Key。
- 将图片发送到第三方 API 前必须清晰提示用户，并允许取消。
- 若模型只返回文字/坐标，不得把文本或矩形框伪装成精确人物 PNG；需要真实 mask 分割流程。
- 没有真实修复/分割模型时，明确显示未配置，不能假装成功。
- 实现 ZIP 导出；浏览器无法选目录时提供 ZIP 下载降级。
- 每个人物一个透明 PNG；不为每个人物创建子文件夹。
- 支持按原图分类与全部汇总两种导出。
- 单张失败不影响整个批次；原图不覆盖。

## 页面
1. 主页面：多图选择/拖拽、缩略图、输出模式、主按钮、真实进度。
2. 结果页：按原图分组展示人物缩略图，可预览、删除误识别结果、重试失败任务。
3. 设置页：API Base URL、model ID、Key、测试连接、测试视觉输入、外发图片提示。
4. 错误提示：未配置、API 超时、模型不支持视觉输入、无人物结果、导出失败。

## 流水线
读取并校验图片 →（用户确认后）调用 DeepSeek 分析 → 水印区域 mask → 真实 inpainting → 实例分割 → 每个人物独立 mask → 合成透明 RGBA PNG → 校验 alpha/坐标/空结果/重名 → 导出 PNG/ZIP/CSV。
