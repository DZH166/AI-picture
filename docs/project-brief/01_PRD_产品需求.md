# 产品需求文档 PRD
## 产品定位
轻量 Web 应用。员工导入带水印的卡通人物拼图，点击“一键提取无水印人物”，系统依次执行水印定位/修复、人物实例分割、透明 PNG 导出。员工不需要分别运行去水印与抠图。

## 使用条件
1–4 人，每周几十张；不租 GPU、不维护 GPU 服务器；电脑配置不统一；图片尽量本地处理；DeepSeek API 能力按实际验证结果接入。

## MVP 功能
1. 支持 PNG/JPG/JPEG/WebP 多图选择/拖拽。
2. 显示缩略图、文件名、分辨率和大小。
3. 主按钮“一键提取无水印人物”。
4. 流程：分析 → 水印区域定位 → 修复 → 卡通人物实例分割 → 透明 PNG。
5. 显示真实进度、状态、人物数、失败原因。
6. 结果网格预览、放大、删除误识别结果、重试失败项。
7. 导出模式：按原图分类（每张原图一个文件夹，里面直接放多个 PNG）；全部汇总到一个文件夹；可选 ZIP。
8. 不为每个人物创建子文件夹。PNG 必须含 alpha；不覆盖原图。
9. 建议输出 CSV 报告。
10. 所有按钮必须真实工作；不能假进度或假成功。
11. 图片发给 DeepSeek/其他第三方 API 前，明确告知用户。
12. API/模型不可用时清楚报错。

## 角色
员工：导入、开始、检查结果、导出。
管理员：配置 API Base URL、model ID、API Key，测试连接和视觉输入，选择是否允许图像外发。Key 掩码显示。
注意：纯前端无法真正隐藏用于浏览器请求的 Key；若未来需要严格保密和限额，需要服务端代理。

## 导出
按原图：output/source_A/source_A_001.png；汇总：output/source_A_001.png。文件名清理非法字符、避免覆盖。

## 质量要求
分离每个独立卡通人物，而不是只裁整张主体；尽量避免漏检、粘连和边缘缺失。水印覆盖的原始像素无法保证恢复，难例标记复核。只处理自有或授权素材。
