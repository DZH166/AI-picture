# 环境配置与 API 适配说明

## 设置页
提供 API Base URL、model ID、API Key、请求超时、是否允许图像发送给 DeepSeek。Key 只显示掩码，提供“测试连接”和“测试视觉输入”。

## 密钥注意事项
不要把真实 Key 提交到 Git。`VITE_*` 环境变量通常会进入前端打包产物，不能当作秘密存储。若坚持纯前端直连，使用者可能从浏览器环境提取 Key；README 必须如实说明。真正隐藏共享 Key 需要后端代理，但本 MVP 不强制增加后端。

## API 适配
- 按官方文档和用户实际可用请求示例实现；不猜 endpoint、model ID、图片字段或响应结构。
- 确认模型是仅文本、支持视觉输入，还是支持图像输出。
- 文字描述不是像素级 mask。
- 对坐标做范围校验和缩放映射。
- API 失败、限流、超时、模型无视觉能力时，显示可理解错误。
- 调用外部 API 发送图片前提示用户。
- 日志不记录 Key、Authorization header、base64 图片或敏感原图内容。
- 提醒管理员核查 API 数据政策与模型商业许可。
