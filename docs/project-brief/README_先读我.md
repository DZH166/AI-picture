# AI 素材工厂 Codex 启动包
本包用于在 Codex 中启动 AI 素材工厂 MVP。

目标：1–4 名内部员工，每周几十张授权卡通拼图；一键执行“水印修复 → 独立卡通人物分割 → 透明 PNG 导出”。不租 GPU、不维护 GPU 服务器。

重要约束：
- 图片和结果尽可能留在用户本地；若把图片发送给 DeepSeek API，必须明确提示，不能称为完全本地。
- 按用户真实验证的 DeepSeek API 文档和请求示例实现，不猜模型能力。
- 视觉理解、像素级修复、实例分割是不同能力；文字描述不是精确 mask。
- 不把 API Key 写入源码、Git 或日志。纯前端调用不能可靠隐藏 Key，文档需说明。
- 只处理自有或获授权素材。

文件：01_PRD、02_技术架构、03_开发计划、04_Codex完整提示词、05_API适配说明。
使用：将目录放入 Codex 工作区，把 04 文件全文交给 Codex。先实现可运行骨架和测试，再接入真实 API，用真实授权图片验证。
