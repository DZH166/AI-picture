## 当前边界

本地算法按连通区域生成候选，不能保证候选数等于人物数。相连人物、离散配件、封闭孔洞和抗锯齿边缘需要人工检查；本地模式不执行水印修复。

大图处理最长边为 1600 像素，输出基于该尺寸。图片、结果和 API Key 仅驻留本次页面内存，刷新前需要导出；没有素材历史库、任务恢复或共享队列。

纯前端 Key 对当前浏览器使用者可见。图片只在视觉测试获得本次确认后发送到配置地址；本地提取不外发图片。
