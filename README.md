# AI-picture · 素材处理

版本 0.2，重建分支 `rebuild-v2`。办公室一台电脑运行，员工通过局域网使用。页面只有员工区和管理员区。

**真实 DeepSeek 与 fal 适配器已实现；尚无真实 Key，未执行业务样图调用，不能据此认定去水印效果或 90% 覆盖率已达标。** 所有新生成结果先标为「待检查」，检查后才能确认下载。旧 0.1 版保留在 Git 历史。

## 启动

需要 Node.js **24.19 或以上的 24 LTS**（使用内置 SQLite）及 pnpm。首次安装、构建：

```powershell
cd "D:\AI素材工厂\ai-material-factory"
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

依赖和构建已完成的本机可直接双击 `启动素材工厂.cmd`。使用期间保留窗口，按 Ctrl+C 停止。管理员打开 `http://127.0.0.1:3000`；员工使用启动窗口显示的 `http://主机局域网IP:3000`。办公室网络需允许入站 TCP 3000，不需要 GPU。

首次在**服务主机本机**进入管理员区，设置至少 10 字符的密码，再分别保存一个 DeepSeek Key 和一个 fal Key。没有默认密码。DeepSeek 连接测试读取模型列表；fal 测试会发送一张程序生成的小图并产生一次真实推理费用，需单独确认。Key 的「已配置」状态不代表连接已实测成功。支持替换、删除和停用。

员工电脑不能打开管理员接口，密钥不经过员工浏览器。浏览器无需注册，使用 HttpOnly 会话 Cookie 隔离各自任务；同一浏览器下的标签共享任务。清除 Cookie 或换浏览器后无法恢复旧会话。重启服务不会重新提交未完成的计费请求，需要员工主动继续。

## 员工操作

1. 上传一张 PNG、JPG 或 WebP 拼图，点击「去水印并提取素材」。
2. 阅读原图及相关裁剪图发送到 DeepSeek 和 fal 的说明，可以取消。
3. 查看真实处理阶段和结果。点击素材，左侧对应原图位置，右侧为实际 PNG。
4. 检查五官、文字、水印和边缘。需要时在详情内补框、调整范围、合并同一设计的片段，或用画笔添加/擦除水印蒙版；只重做该素材。
5. 确认后下载单张 PNG，或「确认并下载全部」。ZIP 根目录直接放 PNG，不附报告或额外目录；失败和未生成素材不进入 ZIP。

提取对象包括人物、头像、动物、完整文字设计、徽章和花纹。矩形海报、国旗可保留整个版面。单图限制 25 MiB、4000 万像素；服务端按 EXIF 方向归一化为 PNG，保留原分辨率，不再缩到 1600 像素。原图和结果默认保留 24 小时，刷新可以恢复本浏览器任务。过期任务自动清理，请及时下载。

## 处理链与预算

- DeepSeek `deepseek-flash`：全图盘点 + 四个重叠分块复核，返回完整设计、稳定 ID、原图坐标及水印候选。
- fal `fal-ai/sam-3/image`：根据提示和候选区域生成真实像素蒙版。独立贴纸移除外部背景，完整矩形保留内部背景。
- fal `fal-ai/object-removal/mask`：只修复可靠水印蒙版与保留前景相交的区域。定位不可靠、覆盖过大或修复失败时保留原像素并提示复核。水印影响轮廓时，修复后最多再分割一次。
- 后端使用原图 RGB、前景 alpha 和局部修复合成 PNG；修复范围之外 RGB 保持原样。遮住的细节属于模型推断，不能保证恢复真实干净原像素。

每图默认上限 **10 元**。每次计费提交前，应用预留 DeepSeek 0.15 元、SAM 0.05 元、修复 0.20 元；局部重做和失败请求均累计。预留是保守的程序控制额，**不是服务商实时账单或最终人民币价格保证**，实际价格、汇率与扣费以账户记录为准。预计超限会暂停；管理员可在折叠辅助信息内提高该任务总预算，员工再点击继续。应用不盲目重发已提交的计费请求，取消也无法保证免除上游已发生费用。

主机全局一次执行一个任务，其余排队；单素材失败保留其他输出。取消或预算暂停后仍可检查、下载已有结果。

## 本机数据与安全

默认存储目录为 `%LOCALAPPDATA%\AI-picture`，位于 Git 仓库之外，包含 SQLite 元数据、加密配置、加盐密码哈希及临时图片。Key 使用 AES-GCM 加密，本机主密钥独立保存并设置当前用户文件权限；这不替代操作系统账户保护。配置响应只给掩码和启停状态。下载、原图、修正、状态接口均验证员工会话归属。

可通过系统环境变量 `AI_PICTURE_DATA_DIR` 指定其他**仓库外**目录，`PORT` 修改端口。可选 `DEEPSEEK_API_KEY`、`FAL_KEY` 只在首次未配置时导入；管理员页面是推荐配置入口。`.env.example` 仅是变量说明，启动脚本不自动加载 `.env`。不要把 Key 写入 `VITE_*`、源码或 Git。备份本机配置时应同时妥善保存数据库和主密钥，否则加密值无法恢复。

本版本是可信办公室局域网部署，监听 `0.0.0.0`；不配置公网暴露。管理员接口同时限制请求源为本机和本机 Host，并需要密码；员工及管理员写操作检查同源请求标记。fal 处理本身涉及供应商临时媒体存储，详见适配器说明。

## 开发与检查

```powershell
pnpm dev        # Node 后端 3000 + Vite 本机开发页 5173
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

`pnpm start` 和 `pnpm preview` 都运行实际后端并提供 `dist` 页面，不能只把静态目录部署到网站托管。

主要入口：`src/App.tsx` 员工流程，`src/components/AdminPanel.tsx` 管理员，`src/components/AssetEditor.tsx` 修正；`server/app.ts` 会话/任务/下载接口，`server/processor.ts` 处理编排，`server/imaging.ts` 原图合成，`server/providers/` 云服务适配，`server/store.ts` SQLite 和密钥存储。
